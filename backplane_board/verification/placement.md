# 部品配置・取付穴の照合

対象はKiCad 10.0.5の[配置基板](../backplane_board.kicad_pcb)、[取付図](../mechanical/placement_review.pdf)と[支持板CAD](../mechanical/README.md)。基準回路はコミット `9b90463`。基板は配線前の状態で検査した。

| 照合対象 | 方法 | 結果 |
|---|---|---|
| 回路と基板の対応 | 階層展開したKiCad XMLの（実部品番号、ピン番号、ネット名）を保存後のPCBから読み戻して比較。KiCad DRCの回路図パリティも実行 | 電気部品・TP計47、450ネット、948端子一致。回路図との差異0 |
| カード嵌合と取付 | 全14ソケットのa1、b1、b列最終端子と両フランジ穴を配置基準と比較。J2/J3の中心間隔と全PWMの共通高さを確認 | 160極は上下133.35、48極の中心は全12枚Y=131.025。フランジ穴のXは全てb列より0.30小さい |
| 配置DRC | 本基板を `kicad-cli pcb drc --schematic-parity` で検査。未配線項目を別集計 | DRC指摘0、回路図パリティ0。未配線接続498。トラック・ビア・銅箔ゾーン0、機械固定用の禁止領域82 |
| Gerber外形 | Edge.CutsのGerberの8線分を読み、端点・閉鎖形状を外形の頂点と比較 | 425.28 × 262.05、四隅C2。全端点一致 |
| Excellonドリル | PTH／NPTHを別出力し、穴中心・工具径・個数をPCBの全ドリルパッドと比較 | PTH 898、NPTH 82一致。NPTHの内訳はレール22、局部支持32、ソケット耳28 |
| 実装位置出力 | KiCad POS出力を読み、購買対象部品を参照番号・位置・回転・面でPCBと比較 | 32点一致。測定パッド15点はPCBデータ上で別途照合 |
| 支持板とサービス開口 | DXFを再読込みし、座標系を変換して円の中心・径をCSVおよび基板穴と比較。背面部品の包絡矩形と開口境界を照合 | DXFは68穴（共通54、支持板専用14）。背面部品とTPは全て開口内。ソケット固定耳はPCBのみ。M3部の背面ねじ頭用Ø6範囲と補強棒の重なり0 |
| 機構モデルと閲覧図 | DXF監査、FreeCAD 1.0でSTEPを再読込みしてソリッド数・妥当性・外形を確認。支持板体積を開口と穴の計算値と比較。配置PDFを描画して表面・背面・取付図の3ページを目視 | DXFエラー・修復0、STEPは妥当な3ソリッド。外包425.28 × 262.05 × 33.00、支持板体積286075.754 mm³ |

実カード、ねじ頭とガイドの干渉、嵌合公差、荷重時の変形、LVDSの信号品質は実測前。取付穴の導体禁止領域は信号GNDと筐体の意図しない接触を避けるために設けた。実機で合わせる寸法は[機構仕様](../mechanical/README.md)に記載した。

# バックプレーン回路の検証記録

本記録の対象は[設計ファイルのSHA-256一覧](design_sha256.txt)で特定する。回路の読み方と電力条件は[基板仕様](../README.md)、比較に使った図面は[資料目録](sources.csv)を参照。

## KiCadと結線

Windows版KiCad 10.0.5で階層を読み込み、KiCad形式に保存し、ERC、XMLネットリスト、全体PDFを出力した。[ERCレポート](erc.rpt)はエラー0、警告0。個別のERC除外は追加していない。各物理端子の接続集合を別に作り、XML出力の450ネットと突き合わせた。

| 検証対象 | 照合条件 | 結果 |
|---|---|---|
| マスタ→PWMおよびPWM→マスタ | 全スロットで8対、Pはa列、Nはb列。同じスロットの2端子だけで1ネット | 96対、192本一致。誤スロット接続、P/N交換、余分な分岐0 |
| 保護電源 | J1-1→F1→Q1-D、Q1-S→全分岐。D1-K＝S、D1-A＝G。Q1のゲート抵抗はGNDへ | ピン番号を含め一致 |
| 分岐出力 | 各ヒューズの後段は自身の測定パッドと同一カードの2電源接点のみ | マスタ1系統＋PWM12系統が独立 |
| リターン・開放 | マスタc列94接点とPWM各10接点のGND、各PWMの予約20接点 | 240接点は個別NC。他に孤立した実装端子なし |
| 部品表 | 実部品番号、メーカー型番、フットプリント、通販URLと数量をXML出力と比較 | 購入9型番、33点。銅箔のみのTP 15個は発注対象外 |

再検査は基板ディレクトリで実行する。検査スクリプトはPython標準ライブラリのみを使う。

```text
kicad-cli sch erc --exit-code-violations -o erc.rpt backplane_board.kicad_sch
kicad-cli sch export netlist --format kicadxml -o backplane.xml backplane_board.kicad_sch
python verification/check_netlist.py backplane.xml
```

## PDFと調達

PDFはA3横、17ページ。先頭図、電源回路、96極、48極の各代表ページを拡大して信号ラベル・余白・電源記号を確認した。ページごとの展開はPDFのテキストから12組のスロット名・J/F/TP番号を照合し、一覧画像で頁の欠落とレイアウトを確認した。繰り返しページの全端子文字を個別に目読した検査は行っていない。

[BOM](../BOM.csv)は回路図から出力した部品番号で集約した。Stock_displayは2026-11-20に参照した正規販売店ページの掲載数で、参照したページの取得時期も併記した。各数値は発注時の引当数量ではない。マスタ、PWMカード上のLVDS送受信器、光部品および嵌合相手は各カード側の部品表に属する。

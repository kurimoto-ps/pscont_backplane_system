# 筐体・実機と合わせる条件

## 6Uカードの前面と後端

マスタとPWMカードは既設6U VMEカードと同等の外形とする。寸法比較には標準基板高さ233.35 mm（3Uは100 mm）を用いた。カード奥行きと前面幅（HP）は既設品で確認する。[Schroff Design Guide「Printed boards」](https://www.digikey.sg/Site/Global/Layouts/DownloadPdf.ashx?pdfUrl=044BECE460B74307A75CB81661D5BB75)

- **PWMカード前面**　6チャンネルに対し、HFBR-1522ETZ（ゲート指令送信）とHFBR-2522ETZ（ゲート異常受信）を各6個置く。水平型の単体外形幅12.19 mmを使い、連結による重なりを見込まず板端に一列に置くと12個で約146 mm。プラグをつかむ間隔、CH番号表示、上下の取手はこの寸法の外。6UではCHごとに送受信を隣接させる案を基準に、実プラグの抜き差しを確認する。[送信器外形](https://uk.rs-online.com/web/p/fibre-optic-transmitters/1894820)・[受信器外形](https://th.rs-online.com/web/p/fibre-optic-receivers/8019263)・[Broadcom外形・連結図 pp.4–6](https://www.farnell.com/datasheets/4321859.pdf)
- **マスターカード後端**　J2（三相6枚）とJ3（チョッパ6枚）に160極を1個ずつ割り当てた。マスタ上のオス本体は94 mm×2。長辺を一列に並べた外端間距離は「コネクタ中心間隔＋94 mm」で、基板高さ233.35 mmに対して取手・ガイド・基板端余白を別に確保する。既設機の実寸で位置を決定する。[嵌合寸法](../verification/card_connectors.md)

## 実機との照合

| 対象 | 設計上の決定 | 次工程で照合する値 |
|---|---|---|
| マスタの嵌合 | 02011601101×2を同一カードに実装。J2/J3のz16・z17は共通のF2後12 V | 既設カードとガイドの位置、中心間隔、ストローク、誤挿入防止キー、実挿入力。メス2個の規格上限の合計は320 N。既設VME信号バックプレーンと本電源用バックプレーンは異なる端子割り当て |
| PWMカード | 48極の2C、各カード2接点並列給電、2接点帰路 | 新作PWM用は09231486921。相手基板の実装向き・嵌合高さ。3相用とチョッパ用の誤装着はマスタのスロット構成とカード機種照合で運転禁止 |
| 配電 | 12 V入力10 A、連続割当7.25 A。無通電挿抜 | 筐体内最高温度、全カード起動時の突入波形、電源の電流制限・短絡電流、ヒューズ溶断曲線と上位保護の協調、最遠カードまでの往復降下0.30 V以内 |
| 同期と故障停止 | REFCLKとSYNC、SLOT_OK_NとRUN_PERMIT_Nをスロットごとに直結 | カード側の終端・開放時の論理、断線／片線断／電源喪失時の点弧禁止。光エラーから最終ゲートまでの最大時間と光出力間の許容スキューは電源側要求で定め、全装着時に測る |
| 基板 | 各P/Nを隣接配線し連続GNDを参照。コネクタはメーカー図とパッド座標を照合 | カード寸法、板厚、固定具、100 Ωスタックアップ、接点部の反射、実際のガーバー・ドリル・印刷開口を照合 |
| 発注 | BOMは調達サイト掲載値を参照。測定パッドは銅箔 | 発注時に数量・納期を再確認。型番先頭のゼロを保持 |

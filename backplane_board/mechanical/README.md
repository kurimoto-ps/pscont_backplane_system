既設6Uクレートに、新作マスター1枚と同じ形状のPWMカード12枚を挿すための配置図。基板・支持板ともにカード挿入側から見た外形左上をXY基準とし、右が＋X、下が＋Y。DXF・STEPはCADの慣例に合わせて左下原点、上が＋Y。両者の換算は `Y_CAD = 262.05 − Y_表`。STEPのZ=0は支持板前面、＋Zがカード側。

## 板金と締結

支持板はA5052-H32、厚さ3.0 mm。表面から10 mm離してバックプレーンを搭載する。外形の下寄りに工具窓を2個設け、板を装着した状態で電源線の着脱、ヒューズ交換、測定を行う。窓の角はR3。左窓はX=5–190、右窓はX=236–420.28、両方ともY=178–220.05。切断端を面取りし、電源ケーブルの張力は別途クレート側のクランプで受ける。

| 配置 | 締結と荷重の経路 |
|---|---|
| 上下レール固定 | PCBは各段11穴、Ø2.7 NPTH。Y=3.10 / 258.95、X=6.90から40.64ピッチ。M2.5ねじを正面から絶縁ワッシャ、PCB、長さ10の筒スペーサ、支持板の順に通し、レールのねじ溝に締結。スペーサ外径は5.5以下。ねじ長はレールの有効ねじ深さと底突き余裕で決める |
| 支持板の先付け | 上下レールに各2穴、計4穴（CSVのR1–R4）で先に固定。低頭ねじの頭は10 mmの空隙内に収める。これら4本はPCBを貫通しない |
| 挿入力の支持 | Ø3.2 NPTH計32穴。長さ10、対辺5.5のM3両メネジ六角支柱を支持板に背後から固定。PCB正面から絶縁ワッシャ・M3低頭ねじで支柱へ締結。締結部は筐体導体と信号GNDを絶縁する。両端のねじ長は支柱内で干渉しないように選ぶ |
| ソケットの耳 | J2・J3とJ11–J22の各2穴、計28穴はØ2.85 NPTH。メスをPCBへM2.5で固定し、抜去荷重を基板に伝える。支持板側にはこの28穴を設けない。フランジ座面に適合するねじ頭、背面のナット・ねじ先突出6 mm以下を嵌合状態で照合する |
| 背面補強 | 支持板中央のウェブにA6061-T6角棒2本。断面12 × 30、長さ246、X中心198 / 228、Y=8–254、30が奥行方向。各5箇所を支持板の前からM4×12低頭ねじで締結。支持板穴Ø4.5、角棒M4×0.7、有効深さ10、下穴Ø3.3深さ12。補強材STEPは下穴を表示。正面側の頭とカードコネクタのはんだ端の空隙を確保する |

支持板と補強材のSTEPは3ソリッド。ねじ、PCB、既設レールは取付図・座標表で指定している。PCB裏面から支持板背面まで13.0 mm、補強材背面まで43.0 mm。既設レールが直接PCBを受けている場合は、PCBの嵌合位置を維持したまま、レールの取付面を13.0 mm後方へ移せるか確認する。補強材・ねじ頭と上下の横桟の背面形状も重ね合わせる。嵌合面の奥行きはカード実寸を優先する。

## 保守面と基板設計

カード側に14個の縦型メスを配置した。J1・F1・Q1・D1・R1と全分岐ヒューズ・測定パッドは背面の開口内。J1は横入線、1番が+12 V、2番が0 V。TP1は保護後12 V、TP2は0 V。背面図は実機を後ろから見た向きで、端子番号は基板のパッドと照合している。機械穴とソケット固定耳の周囲には全銅層の配線・ビア・銅箔禁止領域を配置した。

基板は未配線。KiCadの6銅層は配置検討用の仮設定で、製造用の積層・銅厚・100 Ω差動の線幅は配線工程で確定する。製作前には既設筐体の有効幅、レールのねじ・奥行き、ガイド溝、前板幅、光プラグと取手の干渉、電源線と工具の作業空間を実測する。ダミーカードで2個のマスターコネクタが同時に全嵌合するかを確認し、嵌合部両端の変位と抜去後の残留変形を測る。確定したカード・コネクタの許容ずれに照らして支持を判定する。
